Employee Performance · Dark navy theme · Pop-out filters
1
Open Power BI & Set the Canvas
Start a blank report and match the 1280×720 canvas from the design.
1.1 — Open Power BI Desktop

Launch Power BI Desktop. Close the splash screen. You'll see a blank white canvas.

1.2 — Set Canvas Size

Click anywhere on the blank canvas (not on any visual).

View› Page View› Actual Size

Then in the Format pane on the right, expand Canvas Settings and set:

PropertyValue
TypeCustom
Width1280
Height720
1.3 — Set Page Background

Still with nothing selected, in the Format pane find Canvas Background:

PropertyValue
Color#0B1929
Transparency0%
1.4 — Name the Page

Double-click the Page 1 tab at the bottom and rename it to Dashboard.

2
Connect Your Data
Load the QCFBIDEMPLOYEEPERFORMANCEPRODUCTION table from your data source.
2.1 — Get Data
Home› Get Data› More…

Choose your source (SQL Server, Snowflake, SharePoint, Excel, etc.) and connect to your table.

Tip: If you're using the .pbit template I gave you, double-click it — Power BI will ask for your credentials and auto-map all columns.

In Power Query Editor, confirm these key columns exist:

KPI CARDS
7
Create DAX Measures
These power your KPI cards and charts. Create them before adding visuals.
7.1 — Open the DAX editor

In the left sidebar click the Table view icon, select your table, then click New Measure in the ribbon.

7.2 — Create each measure (copy & paste)
Measure NameDAX Formula
Total Forms COUNTROWS(EmployeePerformance)
Pass Rate % DIVIDE(COUNTROWS(FILTER(EmployeePerformance, EmployeePerformance[FORMPASSFAIL]="Pass")), COUNTROWS(EmployeePerformance), 0) * 100
Avg Score AVERAGE(EmployeePerformance[TOTAL_SCORE])
Target Met % DIVIDE(COUNTROWS(FILTER(EmployeePerformance, EmployeePerformance[TARGETMET]=TRUE())), COUNTROWS(EmployeePerformance), 0) * 100
Tip: After creating each measure, right-click it → Format → set decimal places to 0 or 1 as needed.

14
Pop-out Filter Button with Bookmarks
This is the key step that makes filters hide/show like the preview.
14.1 — Group your slicer panel

Hold Ctrl and click the panel background rectangle + all 5 slicers + the panel title. Then:

Format› Group› Group

Rename the group FilterPanel in the Selection pane.

14.2 — Open the Bookmarks pane
View› Bookmarks
14.3 — Create Bookmark 1: "Filters Hidden"

In the Selection pane, click the eye icon next to FilterPanel to hide it.

In Bookmarks pane click Add. Name it Filters Hidden.

Right-click the bookmark → Update → uncheck Data, keep Display checked.

14.4 — Create Bookmark 2: "Filters Shown"

In the Selection pane click the eye icon next to FilterPanel to show it.

Click Add in Bookmarks. Name it Filters Shown.

Right-click → Update → uncheck Data, keep Display.

14.5 — Add the Filters Button in the header
Insert› Buttons› Blank

Position: X=1198, Y=17, W=74, H=30

In Format pane:

Button text⊟ Filters
Text color#F8FAFC
Fill#112840
Border color#1E3A5F
Rounded corners6

Under Action: Type = Bookmark → Bookmark = Filters Shown

14.6 — Add a Close button inside the panel

Insert → Buttons → Blank. Position it top-right of the filter panel.

Text: ✕ · Action → Bookmark → Filters Hidden

Add this button to the FilterPanel group so it hides/shows with the panel.

Important: In the Bookmark settings, make sure "Selected visuals only" is OFF so the bookmark affects the whole group.
FINAL POLISH
15
Final Polish & Save as Template
Align everything, disable filter pane, and export the .pbit.
15.1 — Align & Distribute

Select the 4 KPI cards → Format → Align → Distribute Horizontally.
Select the 3 charts → same. Makes everything pixel-perfect.

15.2 — Hide the Filter Pane
File› Options› Report Settings

Uncheck "Filter pane" and "Page navigation" so the report looks clean when published.

15.3 — Save as Template (.pbit)
File› Export› Power BI template

Give it a description like Employee Performance Dashboard – Dark Theme.
Save as EmployeePerformanceDashboard.pbit
